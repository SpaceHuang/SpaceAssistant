## RED / GREEN

- RED：先增加 D-5 分类矩阵，现状 15 项失败，原因是 extractor 缺少 `dynamicKinds`。
- GREEN：新增多值类别 `dynamicKinds`，保留旧 `unknownReason` / `dynamicAccess`；Python、JavaScript/TypeScript、PowerShell 与统一解析失败出口均产出类别。类别包括动态代码执行、读/写目标不确定、删除目标不确定、传输目标不确定、绑定链断裂和分析不可用。
- `open` 缺省 / `r` 模式归读，`w/a/x/+` 归写；Path 读写与 unlink、os 删除、shutil 搬运分别归类。未知调用不提升为风险类别，标为 `path-analysis-unavailable`。
- `script-path-extraction` 新增可选 `dynamicKinds`；旧形状仍允许字段缺省，供后续策略阶段按保守兼容路径处理。toolCallGate 转发 extractor 分类。
- 纯未知写入只产生 `unresolved-write-target`；读、删除、搬运都不会产生写类别。
