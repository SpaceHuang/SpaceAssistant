## RED / GREEN

- RED：先新增 JSONL 端到端测试和同定位键摘要对拍，运行 `npm exec -- vitest run electron/confirmation/securityAuditLog.test.ts -t '脚本发现审计' --reporter=dot`。旧写入路径下 2 项按预期失败：最终 JSONL 没有 `scriptAudit`，相同定位键的摘要为空。
- GREEN：实现共享纯投影器 `src/shared/confirmation/scriptSnippetProjection.ts`；在 `SecurityAuditLog` 的本地文件边界把 transient `scriptAuditInput` 替换为 `scriptAudit`，落盘对象不含原始输入字段。`toolCallGate` 仅在真实 `run_script` 事件中附带 findings 与事实侧 `contentDigest`。
- 结构规则：字符串与数字字面量替换为省略占位，注释替换为 `# …`，保留代码结构；无法闭合的字符串投影成 `[unavailable]`。单条投影最多 2000 字符、审计最多 16 条，任一上限触发 `truncated: true`；`totalCount` 保留投影前发现总数。
- 摘要规则：片段只做换行规范化；不 trim、不截断、不投影，直接计算 UTF-8 SHA-256。定位键仍是 `(pattern, range)`；测试证明同定位键不同原文摘要不同、相同原文可复算。
