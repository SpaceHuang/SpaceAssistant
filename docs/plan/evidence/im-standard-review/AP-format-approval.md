# AP-格式：回退抑制字段与内部契约批准记录

- 批准日期：2026-10-30（Asia/Shanghai）
- 批准人：项目负责人（本会话用户）
- 批准原文：“批准该格式与内部契约”。该确认针对本次请求中列明的技术方案 §3/§9 回退抑制字段、内部回退/重新启用契约与兼容策略。
- 批准依据：`docs/develop/im-remote/in-flight/IM标准模式安全审核替代一刀切技术方案.md` §3、§9。

批准实现的约束：

- 在共享 IM 策略快照中以 `automaticMigrationSuppressedVersions` 保存去重后的行为版本 ID 数组；缺失表示没有主动回退记录。字段非数组、成员不是有效版本 ID、JSON/存储读取失败时，自动迁移必须 fail closed。
- 受控回退和显式重新启用均在同一个 `runInTransaction` 中比较 revision、写入快照/行为版本、更新抑制集合、递增 revision 并追加审计。revision 冲突、审计失败和事务失败不得留下部分状态。
- 普通策略配置写入必须保留抑制集合；重启、升级、revision 变化或无关配置更新不得清除它。显式重新启用是唯一可移除对应抑制 ID 的内部操作；重复回退应再次加入该 ID。
- 抑制作用于共享 IM 策略域，精确针对 `im-standard-v3`。未来版本策略不由本批准外推。
- 旧程序降级兼容性未经证明前，不得降级到会丢弃该字段的旧程序。
- 本批准不包含任何 UI、IPC 或用户可见入口授权；此类工作仍需单独审批。生产版本激活与发布仍须满足技术方案 §9/§10 的完整发布门禁和真实环境验收。
