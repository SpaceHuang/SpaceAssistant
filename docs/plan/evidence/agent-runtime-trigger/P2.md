# P2 阶段验收：五源接线、集成与随机不变量

## 完成范围

T10–T17 的证据分别见同目录 `T10.md`–`T17.md`。五源观测最终进入公共 trigger store、固定 requestId 队列投递和普通 receiver Turn 生命周期；同步模式只在用户确认的 `callbackTimeoutMs=5000`、`maxPauseMs=60000` 下接入 SDK lifecycle。P2 没有扩展方案能力边界。

## 集成与不变量

- 固定 seed `0x51a7` 执行 register/event/cancel/restart/queue/complete 操作；每一步检查单一终态、命中胜者、终态不可复活及容量约束。复现时先发现公共 SQLite 更新可把终态重新写成 matched；加入 SQL 状态转移条件后同 seed 通过。测试见 `electron/triggers/invariants.test.ts`。
- 五源实际接线与 receiver Turn 收敛覆盖 History、双渠道 IM accepted facts、受管进程退出、时间/异步事件、同步 checkpoint；固定 requestId receipt 在恢复时复用，已入队记录不会二次插入。证据见 T10–T16 与各模块集成测试。
- S-01 首次 History 接纳失败后 raw SDK transcript 绕过接纳模板的问题，以 RED/GREEN 测试及 T15/T16 记录核销。已合法接纳历史在撤权后可沿普通历史复用；新来源读取继续做当前授权检查。
- 原飞书/微信 inbox 和 wake 分发行为继续由旧集成回归验证；触发源 facts 不进入旧 platform-im 消费者队列。
