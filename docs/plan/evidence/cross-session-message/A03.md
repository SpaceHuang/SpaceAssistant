# A03 工具发现与结构化读取

## 交付

- `action.session.message.send` 与 `action.session.message.revoke` 已由 `registerBuiltinCapabilities` 注册；精确 toolkit.find 查询返回两个 `act` 描述符，参数 schema 拒绝模型提供的 owner 身份。
- send/revoke 通过现有 handler 复用同一写服务，所有权来自当前 CapabilityContext，回执和稳定 `SESSION_MESSAGE_*` 业务错误按结构化 toolkit 结果返回。
- `SessionQueries.readAgentSessionMessageSource` 根据持久 receipt、source、包络、正文摘要和 fingerprint 调用事实分类器；不会从可见正文解析 source。session.read 对已验证的 agent-session 消息附 `{kind,ownerSessionId,requestId}`，截断正文仍保留 source。
- 原始消息文本仍是被转义的普通用户消息；S02 已验证伪造/导入文本不能建立可信 source，A02 已验证消息正文及错误身份不会生成执行批准。
