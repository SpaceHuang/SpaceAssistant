# P4-01 取消自动导出并核销退出行为

## 实现

- 删除session创建后的备份写入、session更新与标题回填后的schedule、非turn消息追加后的schedule、消息patch后的schedule/终态flush、队列编辑／重排／删除后的flush，以及主进程退出时的pending flush。
- 删除主进程启动时对配置工作目录的既有会话副本扫描清理。升级不会因停用自动导出而扫描、迁移或删除已有`session.json`／`messages.json`。
- 删除`DebouncedSessionBackupManager`及`sessionBackupShutdown`模块。新增`SessionBackupLifecycle`仅串行化底层显式写出与会话删除清理；必要的删除失败重试保留。`SessionBackupManager.backupSession`和`backupPageReader`仍可供底层显式调用，本项不新增用户入口或声称仓内已有显式导出IPC。
- 删除会话时仍清理对应备份目录及附件；附件存储的孤儿清理与可读会话副本分开。

## 验证

- TDD触发回归先红后绿：新增会话和修改会话后不调用导出；排队消息成功编辑返回原有结果且不导出。合并VEXPORT／VDAILY相关回归命令运行10文件，100 passed、25 skipped。
- `electron/sessionBackupManager.test.ts`覆盖底层分页显式写出、读取失败不生成不完整文件、写入失败时保留既有`messages.json`；`sessionBackupLifecycle.test.ts`验证显式调用才写出，并保留必要会话删除清理的有限重试。
- Feishu/WeChat入口、桌面继续IPC、日常动作、队列编辑与存储导出测试均通过；`npx tsc --noEmit -p tsconfig.electron.json`通过；`git diff --check`通过。
- 生产源码调用核对：唯一生产`backupSession`调用位于`SessionBackupLifecycle.backupImmediate`；没有生产业务入口调用该显式方法，没有`DebouncedSessionBackupManager`、schedule/flush helper或退出flush模块。

## 边界

- 自动导出停止后，既有可读副本不再自动更新。没有新增界面或IPC导出入口，底层显式能力保留供后续明确调用。
- 本项只验证本机SQLite、文件系统测试夹具与合成渠道handler，不依赖真实模型或外部IM账号。
