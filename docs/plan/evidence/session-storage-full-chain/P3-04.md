# P3-04 缩减当前信息保存并保持工具恢复

## 实现

- 流式 assistant checkpoint 使用 `assistantOutputCheckpoint`：保存当前已接纳文字/思考和必要的执行 shell 身份，不把累计已完成工具结果、输入或输出重复序列化；执行中或效果未知的 shell 即使没有可清理 PID 也保留最小身份。只有 PID 与 owner token 均可核验时才允许后续进程处置。
- 目标恢复按 toolCallId 从 canonical History 合并已提交工具事实；History 中的 `executionOutcome`、executor entry、错误码和 invocation disposition 经 codec 保留。缺失可靠结果的执行中工具仍按中断失败收敛，`unknown-after-dispatch` 不被改成成功或未派发。
- bounded display 摘要缓存比较结果值身份和成功状态；替换前先扣除旧条目的字节。大字符串在 UTF-8 前缀处截断；对象按深度、最多32个属性/元素及预览预算构造有限投影后再 JSON 序列化。publisher 仍 coalesce 流式事件并在 dispose/abort 时清空待发快照。
