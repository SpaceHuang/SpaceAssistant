- 新增 schema v120 的 `canonical_read_version`。新位置创建时标记为版本1；legacy 位置只在位置键、工作目录身份、session id、session generation、当前数据库 generation、ready 状态和 outbox 无 pending 项均匹配时才能完成切换。未知版本拒绝 canonical 快速读取。

## P2-02 消费者切换与保留引用

- 压缩 replay 与 ContextMeter 在完成列匹配后只从 SQLite canonical History 读取；完成后即使旧 JSONL 缺失也不回退打开文件。尚未完成或身份不符的位置保留 legacy reader。
- startup History recovery 在精确完成位置跳过 terminal、provider retry、usage、final context、tool 与 compaction 的 JSONL 修复；旧 History、entries 和 spill 引用仍由既有 History／retention 所有权路径保护。本阶段未增加物理删除。
- meter 导入由既有 outbox 投影器履行相同 canonical event identity 的投影义务；完成 CAS 检查 pending outbox，避免未完成投影时切换读取来源。
