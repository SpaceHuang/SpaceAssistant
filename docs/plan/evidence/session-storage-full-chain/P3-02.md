# P3-02 活跃会话上下文生命周期

## 实现

- SessionExecutionStore 按 session 持有 SDK SessionContext，并以数据库 generation、transcript version 与 scopeKey 三元组校验热命中；首次读取或任一维度变化时冷加载。
- HostedTurnHandoff 将活跃上下文交给 SDK，跨轮只提交当前已接纳消息的增量；SDK 仅在终态 History 与 transcript 提交成功后发布新版本。完成、暂停和已知失败提交成功均可发布；提交异常、版本核验失败、人工复核/删除导致失效时清除缓存。
- 普通 Hosted 与 Track-scoped 请求只读 transcript 控制行确定版本/状态，Track 请求沿用其已验证输入，不加载共享 session 正文。
- 删除会话清除该 session 的宿主上下文。不同 scope、generation 或 version 不复用旧上下文。
