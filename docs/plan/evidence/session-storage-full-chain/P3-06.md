# P3-06 移除 renderer 历史 seed 与重复合并

## 实现

- `initLiveSessionFromStore` 现在只创建空增量列表，不从 Redux 读取或复制会话历史；`ensureLiveSession` 与 `resetLiveSessionMessages` 也只保留流式／排队增量。
- `resolveSessionMessagesForApi` 通过既有 canonical `chatGetMessages` 读取完整 API 上下文，再合并 live delta，不重复合并 renderer 已加载页。
- ChatView 首屏提交后不再 seed live store；原有消息落库、队列编辑及 turn projection 的数据库提交语义未取消。
- renderer compaction-marker state/hydration 原本被并入本阶段的历史状态移除，随后在 P3-07 改为独立延迟查询以保留展示。
