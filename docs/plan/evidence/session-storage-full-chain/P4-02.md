# P4-02 核销重复职责并生成最终可测构建

## 职责核销

- `chatRunnerService.ts`移除`mergeDbAndLive`、`mergeMessagesByTimestamp`、`resolveSessionMessagesForApi`及对应重复测试。API上下文读取canonical baseline，并仅叠加DisplayOrder live delta；未把旧消息正文搬到另一持久化位置。
- 移除`SessionRecoveryPort`、`createSessionRecoveryPort`、`SessionStorage.recovery`、`globalFence`和`pending-recovery`可用性状态。正常存储availability不再拥有全局扫描编排；保留显式启动History恢复端口，以及目标session transcript恢复适配器。旧全局编排测试替换为端口边界测试。
- hosted terminal验证改为窄读最新History事件，仅核验最新事件类型及ledger元数据；SDK turn结果携带`notDispatchedToolCallIds`，handoff不再扫描全History查找。移除同一消息／usage重复JSON比较，保留终态安全校验。
- 保留底层`SessionBackupManager.backupSession`的理由：显式底层导出能力和会话删除清理仍需它；自动调度与退出flush已在P4-01删除，当前没有生产业务入口调用显式写出。
- 保留`reconcileStartupSessionTranscripts`作为聚焦的兼容恢复原语；它不恢复全局`SessionStorage.recovery`服务。
