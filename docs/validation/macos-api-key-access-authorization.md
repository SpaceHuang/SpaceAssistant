# macOS API Key 访问授权验证记录

对应需求：`docs/requirement/macos-api-key-access-authorization-requirement.md`。

## 自动验证

- 单元测试覆盖新 Key 验证后提交、替换失败保留旧密文、安全存储不可用与读取拒绝的区分、拒绝后不自动重复读取、显式重试，以及 IPC 响应不含 Key。
- 渲染层测试覆盖失败卡片的设置入口、草稿关闭或提交失败后的清理，以及配置快照不包含草稿 Key。
- 本机探针使用无价值的固定测试串，调用 Electron `safeStorage.encryptString` 后立即 `decryptString`；未使用真实 API Key。

| 2026-10-01 | 26.5.2 (25F84) | arm64 | 44.1.1 | 本分支 arm64 分发目录 | `electron-builder --mac --arm64 --dir` | 打包成功；`afterPack` 验证 ripgrep 和 7 个 tree-sitter 资源，并对应用进行 ad-hoc 签名与验证；尚未用真实 Key 操作 UI |

此探针验证 `safeStorage` API 能完成受控读取，不代表首次真实凭据读取的系统提示一定会前置，也不代表拒绝、取消或升级后的行为。
