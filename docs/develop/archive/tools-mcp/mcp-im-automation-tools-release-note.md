# MCP 在 IM 与自动化任务中的能力开放说明

自本版本起，已启用的 MCP 服务和工具可在飞书、微信以及普通 automation 业务回合中被发现和调用。各链路复用桌面端已有 MCP 配置、工具映射、延迟加载、连接管理和结果适配。

每次调用仍按实际链路策略审批。飞书和微信不会继承桌面只读注解免确认；automation 使用既有审批 Agent 判断，审批不可用或结论不明确时不会执行。派发前会复检服务、工具白名单、schema 与连接配置；配置变化后需重新发起调用。

服务停用、工具未勾选、未启用的新发现工具、调用裁剪排除的工具，以及安全审批 Agent 均不会获得 MCP 工具。MCP 服务管理权限、Shell/本地写入等 locked 规则没有扩大。
