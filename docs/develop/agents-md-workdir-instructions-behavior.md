# 工作目录 AGENTS.md 行为说明

SpaceAssistant 会读取当前会话有效工作目录根部的 `AGENTS.md`，并把该请求使用的版本作为项目约定交给模型。首期不搜索父目录或子目录，也不执行文件中的命令或自动跟随文件引用。

## 生效时点

- 会话级开关默认开启。修改开关从下一次 invocation 生效；它与 `SPACEASSISTANT.md` 项目记忆开关互相独立。
- 文件内容在每个新的逻辑模型请求边界重新读取。同一逻辑请求的 provider 重试、以及该请求产生的审批操作，沿用发起请求的快照；工具完成后模型发起新请求时会读取当时磁盘版本。
- 工作目录切换会重新绑定请求和工具执行目录。目录在 provider 响应期间变化时，旧请求产生的尚未派发工具会被拦截。

## 状态与失败

桌面端可查看每个请求的加载状态、版本摘要、加载时间及只读历史正文。历史正文不可用时会明确标注，不会拿当前文件代替旧快照。Feishu 和 WeChat 在本请求未加载指令时通过进度文本提示降级；不会发送完整文件内容。

文件缺失、空文件或功能关闭时，对话正常继续。超出大小或 token 限制、路径不合法、文件类型或编码不受支持、读取失败或读取期间持续变化时，整份不注入；请求状态会显示原因，模型也会收到未加载诊断，避免声称遵循了未读取的文件。修复后需发起下一逻辑模型请求重新读取。

项目文本不能授予工具权限、绕过产品安全规则或替代用户审批。普通文件读取仍遵守现有路径和授权限制。

重启后可以只读查看已持久化的请求快照；未完成 invocation 不会自动恢复执行或重放工具。
