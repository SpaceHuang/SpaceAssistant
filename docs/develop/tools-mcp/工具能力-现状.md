首次来源正文在同一 SQLite transaction 内与 admission 凭据接纳；已接纳 History 后撤权不追溯过滤普通会话历史，新来源读取仍重新授权。队列仅携带固定中性 marker；来源正文保存在 trigger event 和准确 receiver 的已授权 History 中。同步 wait 使用用户确认的 `callbackTimeoutMs=5000ms`、`maxPauseMs=60000ms`；进程重启后不能恢复 SDK 内存 waiter，遗留同步登记明确失败收敛。

实施计划、AC/INV 索引、T00～T22 阶段记录及交付后 T23 评审修复证据见 [`agent-runtime-trigger-execution-plan.md`](../../plan/agent-runtime-trigger-execution-plan.md) 及 [`evidence/agent-runtime-trigger/`](../../plan/evidence/agent-runtime-trigger/)。真实 IM 账号、远程生产策略服务、OS 休眠/恢复、Windows 打包与用户数据库恢复未由本地验证覆盖。
